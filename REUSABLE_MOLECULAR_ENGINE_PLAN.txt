BRANCH MODEL
- explicit parent ownership
- recursive parent/child model
- clicking a hub expands that hub's children
- children grow outward from their parent in the parent's branch direction
- branch follows the parent's live engine position
- switching hubs collapses/reopens correctly
- selecting a real memory can collapse active control branches
- no menu branch may reparent to generic selection/focus state
- support at least root -> hub -> child -> action
